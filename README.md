# Inventory_Agent

Inventory_Agent is a project that provides a ChatGPT-style chatbot capable of answering questions about invertory data in a SQL database using tool calls. 
The system consists of three main components: `mcp_server`, `agent_service`, and `frontend`. Each part works together to allow users to interact naturally 
with a database through a conversational interface.

## Project Architecture

### 1. MCP Server
The `mcp_server` exposes tools that connect to the SQL database and perform queries. These tools are made available for the backend agent to use when processing 
user questions.

- Handles database connections
- Executes SQL queries
- Exposes tools for agent usage

### 2. Agent Service (Backend)
The `agent_service` acts as the backend orchestrator. It uses an agentic framework to process user queries by selecting the appropriate tools and agents.

- Includes an orchestrator to manage workflow
- Two specialized agents:
  - **IP Address Agent** – answers questions related to IP addresses
  - **Account Agent** – answers questions related to accounts
- Integrates with an LLM to:
  - Decide which tools to use for a given question
  - Generate answers using the results from tool calls

### 3. Frontend
The `frontend` provides a chat interface for users.

- Allows users to enter questions
- Displays answers generated by the backend
- Provides a seamless conversational experience

## Features

- Conversational interface for SQL database with inventory data
- Tool-driven architecture with multiple specialized agents
- Integration with LLM for intelligent query handling
- Modular structure for easy expansion and customization

## Installation

Follow these steps to set up Inventory_Agent locally:

1. Clone the Repository
```bash
git clone https://github.com/siddharthbaasri/Inventory_Agent.git
cd Inventory_Agent
```

2. Set Up Python Environment

```bash
python -m venv venv

#On macOS/Linux:
source venv/bin/activate

#On Windows:
venv\Scripts\activate

pip install -r requirements.txt
```

3. Start the MCP Server
```bash
cd mcp_server
python main.py
```

4. Start the Agent Service
```bash
cd ../agent_service
python main.py
```

5. Start the Frontend
```bash
cd ../frontend
npm install
npm start
```
   
After completing these steps, open your browser and go to: http://localhost:3000
